# قطاربان — سورس نسخه اولیه، نه اپ آماده استفاده

برای استفاده شخصی با منبع رجا. در این بسته APK وجود ندارد؛ کامپایل اندروید و آزمایش روی گوشی انجام نشده است. محیط ساخت این گفتگو SDK اندروید و Gradle ندارد.

## انجام‌شده
- فرم فارسی مبدأ، مقصد، تاریخ شمسی و تعداد مسافر؛ تاریخ در API میلادی ISO است.
- نمایش قطارها و لینک HTTPS رجا از پاسخ سرویس؛ ظرفیت باید برای تعداد مسافر کافی باشد.
- ذخیره هشدار برای یک قطار، تاریخ و تعداد مسافر مشخص؛ مدیریت و لغو هشدار.
- Worker اندروید برای بررسی دوره‌ای و اعلان محلی با لینک خرید؛ پس از اعلان هشدار غیرفعال می‌شود.
- سرویس شخصی پایتون و اعتبارسنجی پاسخ‌ها؛ خطای منبع به عنوان «ظرفیت تکمیل» تفسیر نمی‌شود.

## مانع اصلی
تابع search_raja در server/server.py عمداً پاسخ 503 می‌دهد. اتصال واقعی رجا در این محیط تأیید نشده و اطلاعات ساختگی به جای ظرفیت واقعی قرار نگرفته است. حالت نمایشی داده‌ها نیز داخل اپ فعال نیست. برای تکمیل باید یک اتصال واقعی و آزمایش‌شده به جست‌وجوی رجا پیاده‌سازی شود؛ شامل فهرست ایستگاه‌ها، پارامتر جنسیت/نوع سهمیه در صورت نیاز، فهرست قطارهای تکمیل، واحد پول و لینک خرید معتبر. اگر منبع فقط قطارهای موجود را برگرداند، نمی‌توان از نبود یک قطار نتیجه گرفت که تکمیل است.

این نسخه فعلاً انتخاب سهمیه عمومی/خواهران/برادران و رزرو کوپه را ندارد؛ اتصال نهایی باید این فیلترها را در هویت هشدار هم لحاظ کند.

## اعلان
Worker حداقل حدود ۱۵ دقیقه فاصله دارد؛ اندروید و مدیریت باتری ممکن است آن را دیرتر اجرا کنند. در حالت Force stop اعلان انجام نمی‌شود. این نسخه اعلان فوری سروری/FCM ندارد. برای اعلان سریع هنگام بسته بودن اپ، سرویس سرور باید ظرفیت را در فاصله مجاز منبع بررسی کند و پیام Push بفرستد. اینترنت، مجوز اعلان و دسترس‌پذیری منبع لازم هستند؛ اعلان بلیط را رزرو نمی‌کند.

## ساخت
پوشه android را در Android Studio باز کنید. نیازمند JDK 17، SDK 35 و Gradle 8.9 است. در ترمینال با Gradle نصب‌شده:

    gradle -p android :app:assembleDebug

فایل خروجی:

    android/app/build/outputs/apk/debug/app-debug.apk

در صورت قرار دادن پروژه در ریشه یک مخزن GitHub، workflow دستی Build Android prototype نیز APK آزمایشی را می‌سازد. هیچ مخزنی در این گفتگو ایجاد یا تغییر نکرده است.

## سرویس
Python 3.10+ بدون وابستگی خارجی:

    cd server
    python3 -m unittest -v

یک TRAINWATCH_TOKEN تصادفی حداقل ۲۴ کاراکتری در محیط قرار دهید و python3 server.py را اجرا کنید. سرویس فقط روی 127.0.0.1:8080 گوش می‌دهد. برای اتصال گوشی باید پشت یک reverse proxy دارای HTTPS معتبر روی سرور شخصی اجرا شود؛ آدرس HTTPS و توکن در فرم اپ وارد می‌شود. هیچ سرویس عمومی یا سروری در این گفتگو مستقر نشده است. توکن محلی در SharedPreferences خصوصی اپ ذخیره می‌شود؛ این نسخه احراز هویت عمومی و مدیریت کاربران ندارد.

## قرارداد اتصال
GET /search?origin=...&destination=...&date=YYYY-MM-DD&passengers=1
Authorization: Bearer <personal token>

پاسخ:

    {"demo":false,"checked_at":"ISO UTC timestamp","trains":[
      {"id":"stable trip+class identifier","name":"train name",
       "departure":"10:30","price_toman":100000,"seats":2,
       "status":"available","purchase_url":"verified HTTPS Raja booking URL"}
    ]}

status یکی از available/sold_out/unknown است. id باید در جست‌وجوهای متوالی همان سفر و کلاس ثابت باشد. لینک صفحه اصلی، لینک خرید مستقیم یک بلیط محسوب نمی‌شود؛ آداپتر باید مقصد معتبر از همان منبع بدهد. توکن رجا نباید در اپ قرار گیرد. خطا، ریت‌لیمیت یا کپچا باید به خطای سرویس تبدیل شود، نه ظرفیت صفر.

## اعتبارسنجی انجام‌شده
تست‌های پایتون برای ورودی مسیر/تعداد، لینک جعلی، ظرفیت ناسازگار و قطع اتصال اجرا می‌شوند. هیچ تست end-to-end با رجا، آزمون تحویل اعلان گوشی یا کامپایل اندروید در این محیط انجام نشده است.
